# Basic-Calculator

A simple console-based calculator written in C.
This project was developed as a beginner-level exercise to practice fundamental C programing concepts.

## Features


-Basic arithmetic operations:
 
 Addition(+)
 
 Substraction(-)
 
 Multiplication(*)
 
 Division(/)

-Input validation for operators

-Divison by zero protection

-Loop-based structure to allow multiple calculations

##Technological Used

-C Programming Language
-Standart C Libraries:
  -stdio.h
  -stdlib.h

##How It Works

1.The user enters the first number.

2.The user enters an arithmetic operator.

3.The user enters the second number.

4.The program displays the result.

5.The user can choose to perfrom another calculation or exit.
